# Part 2 — Federated methylation: nothing to set up yet

The current experiment is a working single-node research simulation. It compares
pooled, local-only and APPFL FedAvg models using synthetic methylation data or a
coordinator-supplied cohort. It does not execute on partner endpoints.

Partner bundles and remote drivers are unavailable. No partner action is needed.
Before onboarding, a future protocol must define authorized data, patient grouping,
subtype labels, a shared CpG panel, local preprocessing, software requirements and
exactly which outputs are returned. Synthetic PoC scores are not clinical validation.
